# 교육장 IP 전환 도구

교육장에서 사용하는 Windows PC의 Wi-Fi 네트워크 설정을 간편하게 전환하는 도구입니다.

## 주요 기능

- 여러 Wi-Fi 어댑터 중 설정할 장치 선택
- 교육 모드: 안내받은 고정 IP, 게이트웨이, DNS 적용
- 일반 모드: DHCP(자동 IP 및 자동 DNS)로 복원
- 현재 네트워크 설정 확인
- 해당 PC에서 마지막으로 적용된 IP 끝자리 저장

## 다운로드 및 실행

1. 오른쪽 **Releases**에서 최신 버전을 엽니다.
2. `education-room-ip-switch-v1.0.0.zip`을 내려받습니다.
3. ZIP 파일을 풀고 BAT 파일을 더블클릭합니다.
4. Windows의 사용자 계정 컨트롤 화면에서 **예**를 선택합니다.
5. 교육 모드에서는 운영진에게 안내받은 IP 끝자리를 입력한 뒤 사용할 Wi-Fi 어댑터를 선택합니다.
6. 교육 종료 후에는 반드시 **일반 모드 전환**을 눌러 자동 IP와 자동 DNS로 복원합니다.

## 주의사항

- Windows 10/11용이며 네트워크 설정 변경을 위해 관리자 권한이 필요합니다.
- 실행 중 Wi-Fi 연결이 잠시 끊길 수 있습니다.
- 교육장에서 안내받은 IP만 사용하세요. 다른 교육생과 같은 IP를 입력하면 통신 장애가 발생할 수 있습니다.
- 브라우저나 Windows에서 보안 경고를 표시할 수 있습니다. 이 저장소의 소스와 SHA-256 값을 확인한 후 실행하세요.
- 일부 설정만 적용된 상태에서 오류가 발생할 수 있으므로, 실행 화면의 **현재 네트워크 정보 확인**으로 결과를 확인하세요.

## 동작 범위

이 도구는 선택한 Wi-Fi 어댑터의 IPv4 주소, 기본 게이트웨이 및 DNS 설정을 변경합니다. 외부 프로그램을 내려받거나 사용자 정보를 전송하지 않습니다.

## 파일 무결성

Release에 함께 제공되는 `SHA256SUMS.txt`에서 다운로드 파일의 SHA-256 값을 확인할 수 있습니다.

ZIP 압축을 원하지 않는 경우 Release의 `education-room-ip-switch-v1.0.0.bat` 파일을 직접 내려받아 실행할 수도 있습니다.
